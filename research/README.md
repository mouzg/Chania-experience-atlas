# Crete Experience Research v6 — Business age evidence

Data file: `research/data/experiences.json`.
`operator_started_year` is an established company/activity milestone; it is not a tourism launch unless explicitly noted.
`experience_started_year` only when the public source directly supports a visitor activity start; else null.
Filter by 5+/10+/20+ business years and sort by age.
Source evidence and confidence are in each record.
The website embeds a fallback copy of the database for local offline opening; server JSON overrides it on GitHub Pages.
No private property coordinates or base are embedded.
